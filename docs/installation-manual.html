Party Sites CMS

Installation & Setup Manual

Version 0.1 · November 2026

1. Introduction

Party Sites CMS is a complete content management system designed specifically for political parties and civic organisations. It gives your party a professional, multilingual public website that you control entirely — no technical knowledge required after setup.

With this CMS you can:

  • Publish news, events, documents and pages in up to four languages (English, French, Portuguese, Arabic)
  • Accept membership applications and contact messages through built-in forms
  • Upload photos and documents with an integrated media library
  • Choose between two visual themes (Classic and Campaign) and customise your colours
  • Manage multiple editors and translators from a secure admin panel
Who this manual is for: The person responsible for setting up the website — usually the party's IT officer or the person who manages hosting. Day-to-day content editing does not require technical skills and is covered briefly in Section 9.

2. Requirements

Server requirements

Component Minimum version Notes
PHP8.2 or higher8.3 recommended
PHP extensionsBCMath, Ctype, Fileinfo, GD, JSON, Mbstring, OpenSSL, PDO, PDO_MySQL, Tokenizer, XML, ZipMost shared hosts include all of these
MySQL or MariaDBMySQL 8.0+ or MariaDB 10.6+Provided by virtually all hosts
Composer2.xUsed during installation only; available via SSH
Disk space500 MB minimumFor the application, database and uploaded media

What you need before starting

  • A domain name pointed at your server (e.g. www.yourparty.org)
  • An SSL certificate (most hosts offer free Let's Encrypt certificates)
  • An FTP or SSH login provided by your hosting company
  • A MySQL database, username and password (created in your hosting control panel)
  • The CMS installation package (a ZIP file provided by your ADAFP contact)
Node.js is NOT required on the server. All CSS and JavaScript are pre-compiled inside the installation package. You do not need to run any build commands.

3. Getting the installation package

The installation package is a single ZIP file (e.g. cms-0.1.0-20261122.zip) provided by your ADAFP representative. It contains the complete application, including all pre-compiled assets.

You will receive the ZIP by email or via a secure download link. Keep it in a safe place — you may need it again if you ever need to reinstall.

Always use the ZIP provided to you. Do not download the application from any other source.

4. Installation on shared hosting (cPanel / DirectAdmin)

This is the most common setup for parties using providers such as Hostinger, Bluehost, Namecheap, or any African hosting company.

1

Create a MySQL database

Log in to your hosting control panel (cPanel). Open MySQL Databases and create a new database, a new user, and assign the user to the database with All Privileges.

Write down the database name, username and password — you will need them in a moment.

2

Upload the ZIP file

Using the cPanel File Manager (or FTP), upload the ZIP to your home directory (e.g. /home/youraccount/). Do not upload it directly into public_html.

3

Extract the ZIP

In File Manager, right-click the ZIP and choose Extract. This creates a folder called cms (or similar) containing the application.

Via SSH it is: unzip cms-0.1.0-*.zip -d /home/youraccount/cms

4

Install dependencies via SSH

Connect via SSH and run: 

cd /home/youraccount/cms
composer install --no-dev --optimize-autoloader

If Composer is not available, ask your hosting provider to enable it, or upload the vendor directory from a local build.

5

Point your domain's web root to the public folder

In cPanel, go to Domains (or Addon Domains / Subdomains) and set the document root to: 

/home/youraccount/cms/public

This is the most important step. If you skip it, visitors will see a directory listing instead of your website.

6

Set folder permissions

Via SSH:

chmod -R 755 /home/youraccount/cms/storage
chmod -R 755 /home/youraccount/cms/bootstrap/cache
7

Open the web installer

Visit https://www.yourparty.org/install in your browser. The installer will guide you through the remaining steps. Continue to Section 6 of this manual.

5. Installation on a VPS or dedicated server

Follow these steps if you manage your own Linux server with Nginx or Apache.

1

Upload and extract

scp cms-0.1.0-*.zip user@yourserver.com:/var/www/
ssh user@yourserver.com
cd /var/www && unzip cms-0.1.0-*.zip -d cms && rm cms-0.1.0-*.zip
2

Install dependencies

cd /var/www/cms
composer install --no-dev --optimize-autoloader
chmod -R 755 storage bootstrap/cache
3

Create the database

mysql -u root -p
CREATE DATABASE party_cms CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'party_user'@'localhost' IDENTIFIED BY 'StrongPassword!';
GRANT ALL PRIVILEGES ON party_cms.* TO 'party_user'@'localhost';
FLUSH PRIVILEGES;
4

Nginx configuration (sample)

server {
    listen 443 ssl;
    server_name www.yourparty.org;
    root /var/www/cms/public;
    index index.php;

    location / { try_files $uri $uri/ /index.php?$query_string; }
    location ~ \.php$ {
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }
}
5

Open the web installer

Visit https://www.yourparty.org/install and continue to Section 6.

6. Web installer walkthrough

The web installer runs automatically the first time you visit the site. It has five steps.

1 Requirements check

The installer checks that your server meets all requirements. Each item shows a green tick (✓) if it passes, or a red cross (✗) if it fails.

If anything shows a red cross, contact your hosting provider and ask them to enable the missing PHP extension. The most commonly missing ones are GD and Zip — both can usually be enabled from the cPanel PHP settings.

2 Database connection

Enter the database credentials you created earlier:

Field What to enter
HostUsually 127.0.0.1 or localhost
Port3306 (default — leave as is)
Database nameThe database you created in Step 1
UsernameThe database user you created
PasswordThe database password

Click Test connection. If it fails, double-check the credentials in your hosting control panel.

3 Site details

Field Description
Organisation nameYour party's full name — appears in the browser tab and emails
Site URLYour full domain, e.g. https://www.yourparty.org
Default languageThe main language of your site
TimezoneYour country's timezone (e.g. Africa/Khartoum)
Contact emailThe address that appears in notification emails

4 Owner account

Create the first administrator account. This account has the highest level of access.

  • Use a real email address you have access to
  • Choose a strong password of at least 12 characters (letters, numbers and symbols)
  • Write the password down somewhere safe — you will need it to log in
Important: You will be asked to set up two-factor authentication (2FA) on first login. This is required for all Owner and Admin accounts.

5 Finalise

The installer runs the database migrations and marks the site as installed. When it finishes, you will see a success page with two links:

  • Go to admin panel — takes you to /panel/login
  • View your site — takes you to the public homepage
Installation is complete. Continue to Section 7 to configure your site.

7. First-time configuration

After logging in for the first time, go to Settings in the admin panel. Work through each section below.

General settings

  • • Site name — your party's name as it should appear on the website
  • • Default language — the language shown to visitors who don't specify one
  • • Active languages — tick all languages you will publish content in
  • • Maintenance mode — turn this on while you are building the site, so visitors see a "coming soon" message instead of an empty site

Theme & colours

  • • Theme — choose Classic (formal, text-focused) or Campaign (bold, action-oriented)
  • • Primary colour — your party's main colour, used for headers and buttons (enter as a hex code, e.g. #1e3a5f)
  • • Secondary colour — used for accents and highlights
  • • Upload your party logo (PNG or SVG, transparent background recommended)

Email notifications

  • • Notification email — where contact form submissions and membership applications are sent
  • • From name / From email — what members see when they receive emails from your site
  • • Configure your SMTP mail server details (host, port, username, password) so the site can send emails. Most hosting providers offer an SMTP account; check your control panel.

Forms

  • • Contact form — enable or disable the public contact form
  • • Join / membership form — enable or disable the membership application form
  • • Privacy policy URL — link to your party's privacy policy page (required by GDPR if you operate in Europe)

Cron job (scheduled tasks)

For scheduled publishing and automatic maintenance to work, you must add one cron job to your server. In cPanel, go to Cron Jobs and add: 

* * * * * php /home/youraccount/cms/artisan schedule:run >> /dev/null 2>&1

Set it to run every minute (the five asterisks mean "every minute").

8. Managing users

Go to Users in the admin panel to invite your team. There are four roles:

Role What they can do 2FA required?
OwnerFull access to everything — settings, users, all content, form submissions, backupsYes
AdminSettings and content management; cannot manage users or run backupsYes
EditorCreate, edit and publish content; cannot change settingsNo
TranslatorTranslate existing content to other languages; cannot create new contentNo

To add a user, click Invite user, enter their email address and select a role. They will receive an email with a link to set their password.

9. Creating content

Pages

Go to Content → Pages and click New page. Give it a title, write the content using the rich text editor, and click Publish. The page appears on your site immediately. To add it to the navigation menu, go to Content → Menus.

News & posts

Go to Content → News. Posts can be published immediately or scheduled for a future date and time — just set the date before clicking Save.

Events

Go to Content → Events. Add a start date, end date and location. Past events are automatically archived.

Multilingual content

When you create a page or post, it starts in the default language. To add a translation, open the content item and click the language tab (e.g. AR for Arabic). Translators can be assigned this work via the Translator role. Right-to-left languages (Arabic) are handled automatically — you do not need to change anything.

Media library

Go to Media to upload images and documents. Supported image formats: JPG, PNG, GIF, WebP (maximum 10 MB per file). Documents: PDF, Word, Excel (maximum 20 MB). Images are automatically resized for web use.

10. Security & two-factor authentication (2FA)

All Owner and Admin accounts must have 2FA enabled. The system will redirect you to the 2FA setup page on first login and will not let you access the admin panel until it is complete.

Setting up 2FA

  1. Install an authenticator app on your phone. We recommend Google Authenticator or Authy (both are free).
  2. On first login, you will be shown a QR code. Open your authenticator app and scan it.
  3. Your app will show a 6-digit code. Enter it in the box and click Confirm.
  4. You will also be given recovery codes — save these in a safe place. If you lose your phone, you can use a recovery code to log in.

Other security recommendations

  • Use a unique, strong password (at least 16 characters)
  • Do not share your admin login with others — create separate accounts for each person
  • Change the default admin panel path in Settings → Advanced to a custom URL
  • Enable your hosting provider's firewall and malware scanning
  • Keep SSL/HTTPS enabled at all times

11. Backups

The CMS includes an automatic weekly backup system. Backups are stored in the storage/backups/ folder on your server and include both the database and uploaded media files.

To run a manual backup at any time, go to Settings → Maintenance and click Run backup now.

Important: The CMS keeps the 10 most recent backups. Older ones are deleted automatically. We strongly recommend also downloading backup files to your own computer or a cloud storage service (Dropbox, Google Drive, etc.) at least once a month.

13. Getting help

If you encounter a problem not covered in this manual, or if you need assistance with installation or configuration, please contact your ADAFP representative.

When contacting support, please have the following information ready:

  • The URL of your site
  • Your hosting provider's name
  • The PHP version on your server (visible on the Requirements check page during installation)
  • The exact error message you see (or the contents of storage/logs/laravel.log)
